## Part 2: 💡 추가 기능 추천 TOP 5

### 추천 1: 📊 주문 실시간 알림 (SSE 실시간 푸시)

| 항목 | 내용 |
|:---|:---|
| **한줄 요약** | 주문 접수/상태 변경 시 관리자와 사용자에게 실시간 알림 |
| **임팩트** | ⭐⭐⭐⭐⭐ — 실제 배달앱 수준의 UX |
| **난이도** | ⭐⭐⭐ — SSE or WebSocket 구현 |
| **현재 한계** | 관리자가 수동으로 새로고침해야 새 주문을 볼 수 있음. 사용자도 주문 상태를 확인하려면 마이페이지를 새로고침해야 함 |

#### 사용자 시나리오
```
👤 사용자: 아메리카노 결제 완료
🔔 관리자 화면: [실시간 알림 팝업] "새 주문이 들어왔다덕! 🐤 아메리카노 x1"
👨‍🍳 관리자: [준비 시작] 클릭
🔔 사용자 화면: [실시간 알림] "주문하신 아메리카노가 준비 중이다덕! ☕"
👨‍🍳 관리자: [완료] 클릭
🔔 사용자 화면: [실시간 알림] "주문이 완료되었다덕! 맛있게 드시라덕! 🎉"
```

#### 기술 포인트
- **백엔드:** Spring Boot SSE (`SseEmitter`) 또는 WebSocket
- **프론트엔드:** `EventSource` 구독, `notificationStore` 실시간 업데이트
- **관리자:** 자동 새로고침 없이 새 주문 카운트 뱃지 업데이트
- **사용자:** 마이페이지 접속 없이도 브라우저 알림 수신

#### 구현 우선순위
| 순서 | 작업 | 난이도 |
|:---:|:---|:---:|
| 1 | Spring Boot SSE 엔드포인트 구현 | ⭐⭐ |
| 2 | 프론트엔드 EventSource 구독 + notificationStore 연동 | ⭐⭐ |
| 3 | 관리자 페이지 실시간 뱃지 + 사운드 알림 | ⭐ |
| 4 | 사용자 마이페이지 주문 상태 실시간 업데이트 | ⭐⭐ |
