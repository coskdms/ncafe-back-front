# 🦆 고라파덕 카페 AI 에이전트 확장 청사진 (v1.2)

현재의 "장바구니 담기", "페이지 이동" 수준을 넘어, 카페가 제공하는 **모든 기능**을 AI 에이전트가 처리할 수 있도록 하는 확장 계획입니다.

## 1. 핵심 전략: Hybrid Intelligence
에이전트가 모든 질문에 답하고 기능을 수행하기 위해 두 가지 방식을 결합합니다.

- **Agent Tools (Function Calling)**: 실시간 데이터 조회가 필요하거나 액션(주문, 취소 등)이 필요한 동적인 기능에 사용합니다.
- **RAG (Retrieval-Augmented Generation)**: 공지사항, FAQ, 카페 이용 가이드 등 정적이지만 양이 많은 지식 답변에 사용합니다.

## 2. 확장 기능 범위 (Feature Scope)

### A. 액션 및 네비게이션 (Action Tools)
| 기능 | 도구 이름 | 설명 | 상태 |
| :--- | :--- | :--- | :--- |
| **바로 주문 (직접 결제)** | `direct_order` | 장바구니를 거치지 않고 선택한 메뉴를 즉시 주문/결제 화면으로 연결합니다. | ✅ 완료 |
| **상세 화면 이동** | `view_menu_detail` | 특정 메뉴의 상세 정보 페이지(`/menus/{id}`)로 이동합니다. | ✅ 완료 |
| **페이지 이동** | `navigate_to_page` | (기존) 장바구니, 카테고리 목록 등 일반 페이지 이동. | ✅ 완료 |

### B. 주문 및 이력 관리 (Dynamic Tools)
| 기능 | 도구 이름 | 설명 | 상태 |
| :--- | :--- | :--- | :--- |
| **주문 내역 조회** | `get_my_orders` | 사용자의 최근 주문 목록과 상태를 조회합니다. | ✅ 완료 |
| **주문 상태 확인** | `get_order_status` | 특정 주문이 '준비 중'인지 '완료'되었는지 알려줍니다. | ✅ 완료 |
| **주문 취소** | `cancel_order` | 결제 후 대기 상태인 주문을 취소합니다. | ✅ 완료 |

### C. 사용자 맞춤 정보 (Dynamic Tools)
| 기능 | 도구 이름 | 설명 | 상태 |
| :--- | :--- | :--- | :--- |
| **포인트/혜택 관리** | `get_my_growth_info` | 사용자의 현재 등급, 보유 포인트, 다음 단계까지 남은 포인트 등을 조회합니다. (전용 포인트 카드 UI 지원) | ✅ 완료 |

### D. 카페 지식 및 공지 (RAG)
| 데이터 소스 | 처리 방식 | 질문 예시 | 상태 |
| :--- | :--- | :--- | :--- |
| **공지사항/이벤트** | Admin API를 통해 최신 공지 임베딩 | "요즘 진행하는 이벤트 있어?", "오늘의 커피 뭐야?" | ⏳ 진행 중 |
| **카페 운영 정보** | RAG 문서 등록 (영업시간, 위치, 주차 등) | "주차 가능한가덕?", "언제 문 닫아덕?" | ✅ 완료 |
| **메뉴 상세 정보** | 메뉴 설명 및 알레르기 정보 임베딩 | "카페인 없는 음료 추천해줘", "이 메뉴 땅콩 들어있어?" | ✅ 확대 완료 |

## 3. 기술적 구현 및 업데이트 내역

### Step 1: Backend API 연동 확장 (`backend_api.py`) ✅
- `/orders/mine`, `/orders/{id}/cancel` 연동 완료.
- `/members/growth`를 통한 포인트 및 성장 시스템 연동 완료.

### Step 2: Gemini 도구 정의 및 시각화 확장 (`gemini.py`) ✅
- 포인트 및 성장 정보 조회를 위한 `get_my_growth_info` 도구 최적화.
- **성장(포인트) 카드 마커** 도입: `::growth{"level": "...", "points": 1000, "nextLevel": "...", "remaining": 500}::`

### Step 3: 프론트엔드 UI/UX 강화 (`AgentChat.tsx`, `AgentChat.module.css`) ✅
- `direct_order` (바로 주문), `view_menu_detail` (상세 이동) 액션 핸들링 구현.
- `::growth` 마커 전용 **세련된 포인트 카드 UI 컴포넌트** 스타일링 및 실시간 렌더링 추가.

### Step 4: RAG 지식 고도화 (`add_menu_rag.py`) ✅
- 카페인 없는 음료 추천, 알레르기 안내, 시그니처 메뉴 상세 정보 등 **고품질 지식 데이터** 보강.

---

## 4. 기대 효과
- 사용자가 "아이스 아메리카노 결제해줘"라고 말하면 즉시 결제 화면으로 넘어가는 등 **사용자 여정(User Journey)을 획기적으로 단축**합니다.
- "나 몇 포인트 있어?"라고 물으면 텍스트만 나오는 게 아니라, 예쁜 포인트 카드와 다음 등급까지의 프로그레스 바가 출력되어 **사용자 로열티**를 높입니다.
